# R390 Studio

Веб-редактор циферблатов Samsung Galaxy Fit3 (SM-R390).

Текущая опубликованная версия приложения: **R390 Studio v0.6.3**.

## GitHub Pages

После включения Pages для ветки `main` и папки `/ (root)` сайт будет доступен по адресу:

https://yuriyurin.github.io/r390-studio/

## Структура

- `index.html` — загрузчик приложения.
- `app.b64.part01..05` — сжатый пакет R390 Studio.
- `.nojekyll` — отключает обработку Jekyll.

Сам редактор выполняется полностью в браузере.
